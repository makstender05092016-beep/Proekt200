# ПРОЕКТ 200

**Знание. Дисциплина. Совершенство.**
Персональная система подготовки к ЕГЭ-2027: профильная математика и физика (физика — с нуля).
Статическое PWA: HTML + CSS + JavaScript без сборки. Работает офлайн, данные хранятся только на устройстве.

---

## Публикация с iPhone (без компьютера)

Все файлы лежат в одной папке, без подпапок. Так их можно загрузить в GitHub через Safari одним выбором.

### 1. Распакуйте архив
1. Сохраните `proekt200.zip` в приложение «Файлы».
2. Нажмите на архив в «Файлах» — рядом появится папка `proekt200`.

### 2. Создайте аккаунт и репозиторий GitHub
1. Откройте в Safari **github.com** и зарегистрируйтесь (или войдите).
2. Нажмите **«+»** (вверху) → **New repository**.
3. Название: `proekt200`. Видимость: **Public** (на бесплатном тарифе GitHub Pages работает только для публичных репозиториев).
4. Галочки README и прочие можно не ставить. Нажмите **Create repository**.

### 3. Загрузите файлы
1. На странице пустого репозитория нажмите ссылку **uploading an existing file**.
   Если ссылки или кнопки **Add file → Upload files** не видно, в Safari нажмите **«аА»** в адресной строке → **«Запросить настольный веб-сайт»**.
2. Нажмите **choose your files** → **Обзор** → откройте папку `proekt200`.
3. Нажмите **«Выбрать»** (вверху справа), отметьте **все файлы** и нажмите **«Открыть»**.
4. Дождитесь загрузки всех файлов и нажмите внизу **Commit changes**.

Должны быть загружены: `index.html`, `styles.css`, `core.js`, `database.js`, `content-math.js`, `content-physics.js`, `tasks.js`, `viz.js`, `labs.js`, `exam.js`, `app.js`, `sw.js`, `manifest.json`, `icon-180.png`, `icon-192.png`, `icon-512.png`, `README.md`, `PROJECT_STATUS.md`, `single.html`.

### 4. Включите GitHub Pages
1. В репозитории откройте **Settings** (в мобильной версии он может быть в меню «…») → слева **Pages**.
2. **Source:** *Deploy from a branch*. **Branch:** `main`, папка `/ (root)` → **Save**.
3. Через 1–3 минуты вверху страницы Pages появится адрес вида
   `https://ВАШ_ЛОГИН.github.io/proekt200/`
   (если адреса нет — обновите страницу через минуту).

### 5. Откройте приложение
Откройте этот HTTPS-адрес в **Safari**. Service Worker (офлайн-режим) работает только по HTTPS — поэтому файл, открытый прямо из «Файлов», офлайн-режима не получит.

### 6. Добавьте на экран «Домой»
Safari → кнопка **«Поделиться»** → **«На экран „Домой“»** → **«Добавить»**.
Дальше открывайте приложение только с иконки «ПРОЕКТ 200».

> ⚠️ На iOS данные в установленном на «Домой» приложении и во вкладке Safari **хранятся раздельно**. Занимайтесь в одном месте (лучше — в установленном приложении) и регулярно делайте экспорт.

### 7. Проверьте офлайн-режим
1. Откройте приложение с иконки при включённом интернете, пройдите первый экран.
2. Откройте **Настройки → Офлайн-режим**. Должно быть: *Service Worker: активен*, *Файлов в кэше: 16 из 16*, *Готово к работе без интернета*. Если нет — нажмите «Обновить кэш».
3. Включите **авиарежим**, полностью закройте приложение (смахните его в переключателе приложений) и откройте снова с иконки. Учебники, задачи, лаборатории, экзамены и статистика должны работать.

### 8. Резервная копия прогресса
**Настройки → Данные → Экспорт** создаёт JSON-файл. Сохраните его в «Файлы» или iCloud Drive. После переустановки: **Импорт** → выберите файл. Приложение проверит формат и версию данных.
Браузер может удалить данные сайта (например, при нехватке памяти). Полной защиты от этого нет, поэтому делайте экспорт регулярно.

### 9. Обновление приложения
Загрузите изменённые файлы в репозиторий тем же способом (Add file → Upload files) с заменой. В `sw.js` увеличьте номер в строке `const VERSION = 'p200-v1.0.0'` — тогда приложение покажет «Доступна новая версия» и обновит кэш.

### Резервный вариант: один файл
`single.html` — всё приложение в одном файле (без Service Worker и установки). Он пригодится, если загрузить много файлов не получилось: можно опубликовать только его и открыть `https://ВАШ_ЛОГИН.github.io/proekt200/single.html`. Офлайн-режим и иконка в этом варианте не гарантируются.

## Состав
| Файл | Назначение |
|---|---|
| `index.html` | оболочка, иконки-символы |
| `styles.css` | оформление (эстетика НИИ/ВЦ, мобильная вёрстка, Safe Area) |
| `core.js` | утилиты, ГСЧ, безопасный разбор выражений, единицы и размерности, синтез звука |
| `database.js` | IndexedDB (резерв — localStorage), экспорт/импорт с проверкой версии |
| `content-math.js` | 21 тема математики: учебник, конспект, формулы, примеры, ошибки |
| `content-physics.js` | 29 тем физики с нуля |
| `tasks.js` | 103 генератора задач, проверка ответов, диагностика ошибок, 16 развёрнутых заданий с эталоном |
| `viz.js` | SVG-чертежи к задачам и интерактивные модели тем |
| `labs.js` | 12 виртуальных лабораторий (Canvas) |
| `exam.js` | структура вариантов ЕГЭ, конструктор, подсчёт баллов |
| `app.js` | экраны, учебный план, звания, статистика, библиотека, настройки |
| `sw.js`, `manifest.json` | офлайн-кэш и установка PWA |

## Источники и достоверность
- Структура ЕГЭ по математике — по **проекту КИМ ЕГЭ-2027** (ФИПИ, август 2026): 20 заданий, максимум 33 первичных балла, экономическая задача перенесена в часть 1, добавлены задание на случайные величины и задача на моделирование. Распределение тем по номерам части 1 в тренажёре ориентировочное — сверьте с утверждённой демоверсией на fipi.ru.
- Физика — по **КИМ ЕГЭ 2026** (26 заданий, 45 первичных баллов); по данным о проекте 2027 изменений не заявлено.
- Все тексты и задачи — авторские. Открытый банк ФИПИ **не встроен**. Критерии оценивания развёрнутых ответов — упрощённые, для самопроверки; официальные критерии и шкалу перевода баллов приложение не воспроизводит.
