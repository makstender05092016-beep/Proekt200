# PROJECT_STATUS — ПРОЕКТ 200, версия 1.0.0 (09.11.2026)

## Реализовано и работает
- **Интерфейс**: главный экран «Личное учебное дело № 001» (эмблема, карточка, звание, кольца прогресса, план на сегодня, текущие задания, плитки разделов), нижняя навигация, Safe Area, вертикальная мобильная вёрстка без горизонтальной прокрутки, работа без наведения мыши.
- **Факультет математики** — 21 тема, **факультет физики** — 29 тем (с нуля). У каждой темы: полный учебник (теория, определения, формулы, разобранные примеры, типичные ошибки) и краткий конспект с переключением режимов. У тем с моделью есть вкладка «Модель».
- **Задачи**: 103 генератора с параметрами (числа меняются при каждом запуске), типы — числовой ответ, ответ с единицами, пошаговые задачи, выбор варианта (30 качественных вопросов), соответствие. Сложность — 3 уровня.
- **Проверка ответов**: безопасный разбор выражений (дроби, √, π, степени, запятая), проверка единиц и размерности, в том числе перевод приставок (км/ч → м/с, кДж → Дж, см → м). При ошибке выводится разбор: где ошибка (шаг), почему (распознавание типичных ошибок по заранее рассчитанным неверным ответам, знаку, порядку величины, множителю 2, квадрату/корню), как рассуждать (эталонное решение), верный ответ.
- **Развёрнутые ответы**: 16 авторских заданий (10 математика, 6 физика) с эталонными решениями и самооценкой по упрощённым критериям.
- **Визуализации**: SVG-чертежи к задачам (графики, треугольники, окружность, трапеция, параллелепипед, векторы, мензурка, график v(t), наклонная плоскость, рычаг, электрическая цепь, линза). Интерактивные модели: семейства функций с коэффициентами, единичная окружность, касательная и производная, интеграл как площадь, треугольник с перетаскиваемыми вершинами, 3D-тела с вращением пальцем и сечением куба, векторы, симуляция вероятности, статистика набора.
- **Лаборатории (12)**: наклонная плоскость, законы Ньютона, силы и трение, свободное падение, бросок под углом, столкновения (упругое/неупругое), закон Ома, электрические цепи (3 схемы), маятник (точное уравнение, метод Рунге — Кутты, затухание), волны (поперечные/продольные), геометрическая оптика (тонкая линза + преломление/ПВО), идеальный газ.
- **Экзаменационная комиссия**: полный вариант по математике (20 заданий по проекту 2027) и физике (26 заданий), таймер 3 ч 55 мин, автосохранение ответов, продолжение незавершённых вариантов, проверка, разбор по каждому заданию, самооценка части 2, повторное прохождение (новый вариант или тот же). Конструктор: предмет, темы, сложность, количество, таймер. Контрольные испытания по темам. Входная диагностика (12 задач).
- **Учебный план**: выбор 20/40/60/90/90+ минут, учёт диагностики, слабых тем, ошибок и прогресса, интервальное повторение (1–2–4–7–15–30 дней), перенос невыполненных пунктов без штрафов, ручное добавление/удаление/отметка, пересборка.
- **Статистика**: общий прогресс и по предметам, число задач, процент верных, активность за 14 дней, освоенные и слабые темы, результаты испытаний.
- **Звания** (11, от рядового до генерала): зависят от верных ответов, освоенных и изученных тем, результатов испытаний и активных дней (≥5 задач). Проведённое в приложении время не учитывается. Есть удостоверение, погоны, анимация присвоения, табель о рангах и 17 достижений.
- **Научная библиотека**: 286 записей (формулы и определения всех тем, физические константы, единицы SI), поиск, категории, фильтр по типу, избранное, ссылки на темы и визуализации.
- **Звук**: синтез Web Audio на устройстве (щелчки клавиш, переключатели, терминальные сигналы, запуск, подтверждение, ошибка, награда). Громкость и отключение. Звук только в ответ на действия пользователя.
- **Данные**: IndexedDB (резерв — localStorage). Хранятся прогресс, ответы, экзамены, план, статистика, достижения, настройки, избранное. Экспорт и импорт JSON с проверкой формата и версии, запрос постоянного хранения, полный сброс.
- **PWA**: manifest, Service Worker с кэшем всех 16 файлов, офлайн-навигация, баннер обновления, встроенная проверка готовности к офлайну (Настройки).
- **Резервный вариант**: `single.html` — всё приложение одним файлом.

## Проверено (автоматически, в этой сессии)
- Все 103 генератора × 400 случайных вариантов: в текстах нет NaN/undefined; ответ конечный; эталонный ответ проходит собственную проверку (включая единицы и шаги). Ответы — целые числа или десятичные дроби до 4 знаков.
- Проверка единиц: «72 км/ч» засчитывается как 20 м/с; «20 м/с²» вместо скорости → сообщение о неверной размерности.
- Подсчёт баллов: полный вариант по математике с верными ответами части 1 даёт 13 баллов, при максимальной самооценке — 33/33. Физика: 40/40 по упрощённым баллам тренажёра.
- Сквозной тест в headless Chrome (экран 390×844, касания): первый запуск, главный экран, все 50 тем × 4 вкладки, практика с неверным ответом и разбором, все 12 лабораторий, библиотека, план, статистика, награды, настройки, полный экзамен с завершением и протоколом. **Ошибок JavaScript нет.**
- Офлайн: после первой загрузки Service Worker активен, в кэше 16 из 16 файлов. При отключённой сети перезагрузка страницы, библиотека и лаборатории работают.
- Экспорт проходит собственную проверку формата. `single.html` запускается без ошибок.

## Ограничения (честно)
- Учебники авторские и компактные: это полноценный систематический курс по всем темам программы, но не замена толстому учебнику и задачнику. Объём каждой темы — 1–2 экрана теории плюс примеры.
- Открытый банк заданий ФИПИ **не встроен**. Задачи авторские, генерируемые по образцу типов КИМ.
- Структура ЕГЭ-2027 по математике взята из **проекта** КИМ (август 2026). Разбивка тем по номерам 1–13 ориентировочная, номера 14–20 части 2 восстановлены по описанию проекта. После публикации утверждённой демоверсии нужна сверка.
- Физика — структура КИМ 2026. Баллы части 1 в тренажёре упрощены (число — 1, соответствие — 2), поэтому максимум тренировочного варианта — 40, а не 45.
- Критерии части 2 упрощены для самопроверки; официальные критерии и шкала перевода баллов не воспроизводятся.
- Развёрнутые решения проверяются только самооценкой: надёжная автоматическая проверка произвольного текста решения невозможна.
- Задачи повышенной сложности части 2: 16 статичных заданий (по 1–2 на номер) — для системной подготовки этого мало.
- Шрифты — системные (Avenir Next Condensed, Georgia на iOS); собственные файлы шрифтов не подключались.
- Браузер может удалить данные сайта, абсолютной защиты нет. Поэтому есть экспорт.
- Данные вкладки Safari и установленного на «Домой» приложения на iOS хранятся раздельно.

## Дальнейшие шаги (точка продолжения)
1. Сверить `exam.js → P.EXAM_SPEC` с утверждённой демоверсией ЕГЭ-2027 (fipi.ru), исправить номера и баллы.
2. Расширить банк `P.EXT` (`tasks.js`): по 5–10 заданий на каждый номер части 2.
3. Добавить генераторы: тригонометрические уравнения с отбором корней (краткий ответ), параметры, логарифмические неравенства, задачи на графики производной, оптика (решётка), фотоэффект через длину волны.
4. Расширить учебники: дополнительные примеры с решением в `content-*.js` (поле `ex`).
5. Проверить на iPhone и поправить вёрстку по результатам.
6. При изменениях увеличивать `VERSION` в `sw.js`.

Структура для продолжения: контент — `content-math.js`, `content-physics.js` (функция `T({...})`); задачи — `tasks.js` (функция `G(id, тема, уровень, r => ({q, a, unit, needUnit, sol, diag, viz, steps}))`); модели — `viz.js` (`P.VIZ`); лаборатории — `labs.js` (`L(...)`).
